Fields: Static vs Non-Static

Fields represent the state of an object. Instance variables (non-static) belong to a specific object. Static variables belong to the class itself and are shared across all instances.

public class Student {
    // Instance variable: unique to each student
    String name; 
    
    // Static variable: shared among all students
    static String university = "Global University"; 
    
    public Student(String name) {
        this.name = name;
    }
}

Methods: Static vs Non-Static

Instance methods operate on specific objects and can access instance variables using `this`. Static methods operate at the class level and cannot access instance variables directly.

public class MathUtility {
    int multiplier = 2; // Instance field

    // Instance method: requires an object creation
    public int multiply(int a) {
        return a * this.multiplier;
    }

    // Static method: called via MathUtility.add(5, 3)
    public static int add(int a, int b) {
        return a + b;
    }
}

Getters, Setters & Encapsulation

Encapsulation hides the internal state. Fields are declared `private`, and access is granted via public `get` and `set` methods. This allows validation before mutation.

public class Account {
    private double balance;

    // Getter
    public double getBalance() {
        return this.balance;
    }

    // Setter with validation
    public void setBalance(double balance) {
        if (balance >= 0) {
            this.balance = balance;
        }
    }
}

Passing & Returning Objects

Methods can accept objects as parameters and return objects. When you return an object, you are returning the reference to that object in memory.

public class ProfileManager {
    
    // Passing an object
    public void displayProfile(Student s) {
        System.out.println(s.getName());
    }

    // Returning an object
    public Student createStudent(String name) {
        Student newStudent = new Student(name);
        return newStudent; 
    }
}

Object Mutability During Method Calls

Java is strictly pass-by-value. However, when passing an object, the "value" passed is the reference to the object. Modifying the object's state inside the method affects the original object, but reassigning the reference does not.

public class MutabilityDemo {
    
    public void modifyState(Student s) {
        s.setName("Alice"); // Caller WILL see this change
    }

    public void reassignReference(Student s) {
        s = new Student("Bob"); // Caller WILL NOT see this change
    }
}
