The Bin Packing Problem

The Problem: Given $N$ items of different weights and bins of a fixed capacity $C$, pack all items using the absolute minimum number of bins. Because this is an NP-Hard problem, finding the perfect mathematical optimum is computationally impossible for large sets.

The Greedy Strategy (First Fit Decreasing - FFD): We use an approximation algorithm. First, we sort the items in descending order (biggest items first). Then, for each item, we scan our open bins from left to right and place the item in the first bin that has enough remaining space. If it doesn't fit in any open bin, we open a new one. Sorting first prevents massive items from being stranded at the end with no space left.
Time Complexity: $O(N \log N)$

Sorting the items takes $O(N \log N)$. The subsequent First Fit placement takes $O(N^2)$ in a naive array, but the overall time is bounded by the sort, or can be optimized to strictly $O(N \log N)$ using Segment Trees.

Space Complexity: $O(N)$

We only need an array to keep track of the remaining capacity of each open bin. In the worst case (where every item requires its own bin), this array is size $N$.

import java.util.*;

public class BinPacking {
    
    // First Fit Decreasing (FFD) Approach
    public static int firstFitDecreasing(Integer[] weight, int capacity) {
        
        // 1. Greedy Choice: Sort items in descending order
        Arrays.sort(weight, Collections.reverseOrder());
        
        int res = 0; // Number of bins used
        int[] bin_rem = new int[weight.length]; // Remaining space per bin
        
        // 2. Place items one by one
        for (int i = 0; i < weight.length; i++) {
            int j;
            
            // 3. Scan existing bins from left to right
            for (j = 0; j < res; j++) {
                if (bin_rem[j] >= weight[i]) {
                    bin_rem[j] -= weight[i];
                    break; // Item fits, break inner loop
                }
            }
            
            // 4. If no bin could accommodate weight[i], open a new bin
            if (j == res) {
                bin_rem[res] = capacity - weight[i];
                res++; // Increment total bins
            }
        }
        
        return res;
    }
}
def first_fit_decreasing(weight, capacity):
    
    # 1. Greedy Choice: Sort items in descending order
    weight.sort(reverse=True)
    
    res = 0 # Number of bins used
    bin_rem = [0] * len(weight) # Remaining space per bin
    
    # 2. Place items one by one
    for i in range(len(weight)):
        j = 0
        
        # 3. Scan existing bins from left to right
        while j < res:
            if bin_rem[j] >= weight[i]:
                bin_rem[j] -= weight[i]
                break # Item fits, break inner loop
            j += 1
        
        # 4. If no bin could accommodate weight[i], open a new bin
        if j == res:
            bin_rem[res] = capacity - weight[i]
            res += 1
            
    return res
